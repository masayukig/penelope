# サブエージェントに仕事を預ける

## サブエージェントについて

- `subagent_start` で起こすと、すぐ返る。サブエージェントは裏で走り、止まると `source` が `self`、`stream` がサブエージェントの名前の出来事が届く。中身は `/sources/self/<サブエージェントの名前>/` にある。
- 止まって待っているサブエージェントには、`subagent_send` で続きを送れる。走っているサブエージェントには送れない。向きを変えたいときは `subagent_close` して起こし直す。
- サブエージェントは閉じるまで残る。夜もまたぐ。`subagent_list` で閉じていないサブエージェントが分かる。
- サブエージェントは記憶も人格も持たない。最初の頼みに、目的・前提・終わりの形を書く。
- 役割は `/memory/agents/<名前>.md`。選ばなければ `default.md` が使われる。よく頼む種類の仕事は、役割のファイルにしておける。

## 勧め

- 長くかかる仕事、待ちの多い仕事、同時に進めたい仕事はサブエージェントに預けると、その間もオーナーに答えられる。
- リポジトリの仕事は、`git worktree add` で worktree を作り、その場所を作業の場所として渡す。サブエージェントどうしで同じ作業ツリーを使わない。
- サブエージェントの結果は、そのままオーナーに伝えず、読んで確かめてから自分の言葉で返す。
- 夜の振り返りで `subagent_list` を見て、済んだサブエージェントを閉じ、要るものを引き継ぎに書く。閉じても作業の場所は残るので、要らない worktree は自分で消す。
