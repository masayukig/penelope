# さやかのアバター

`PENELOPE_AVATAR=sayaka` を選ぶと、`/memory/avatar/` がない初回起動時に backend がこのディレクトリを写します。表示名は「さやか」です（[backend のアバター設定](../../../docs/backend.md#アバター)）。

| ファイル | 用途 |
| --- | --- |
| `avatar.json` | ID・表示名と表情ごとの画像の場所 |
| `icons/<表情>.webp` | Web UI 用の 512×512 WebP |
| `slack/<表情>.png` | Slack 用の 256×256 RGB PNG |
| `appearance.yaml`、`sdctl-params.yaml` | 自分を描くときの姿と生成の既定値 |

## 出どころと生成設定

`sdctl` と Stable Diffusion WebUI で生成しました。モデルは [Anima Base v1.0](https://huggingface.co/circlestone-labs/Anima)（hash `bd43b7cffe`）、LoRA はオーナーの `kutara_anima.v12`（強度 1、hash `81068aaf6f61`）です。モデルや LoRA の重みは同梱しません。

- `sdctl-params.yaml` の設定を使い、アイコン用の画像だけ 1024×1024 で生成しました。ER SDE、Simple、32 steps、CFG 4。Shift 3.5、CPU RNG は WebUI 側の設定です。
- 共通のトリガーは `kutara sayaka, blonde long hair, fore head,`、衣装は `white collared shirt, red ribbon bowtie, plaid pattern skirt,`。`safe` を指定し、白い背景の胸から上のポートレートにしました。
- 各表情を 2 枚ずつ生成し、手の仕草が出なかった表情の一部は、仕草をプロンプトの前半にも指定して 1 枚だけ追加しました。通常の自画像の既定は 896×1152 です。

## 選定と切り出し

`neutral` の顔の大きさを基準に寄せ、目の高さを揃えました。頭の上を少し切り、下には襟元を残しています。手が入る絵は、顔を隠さず仕草が読めるものを選びました。座標は 1024×1024 の元画像の左上を原点とし、単位はピクセルです。

| --- | ---: | ---: | ---: | ---: | --- |
| `neutral` | 8196100 | 80 | 45 | 895 | 横目と軽くとがらせた口で、怒りとは違う、普段の少しむすっとした顔に見える |
| `happy` | 8196112 | 312 | 62 | 614 | ウインクと目元のピースが、笑顔を隠さず枠に収まる |
| `laughing` | 8196121 | 107 | 76 | 855 | 閉じた目と大きく開いた笑い口に、顎の横に上げた手が添う |
| `surprised` | 8196132 | 214 | 76 | 610 | 見開いた目と開いた口を、頬を包む両手が囲む |
| `thinking` | 8196142 | 303 | 27 | 570 | 上に向けた視線と顎に当てた人差し指で、考え込む仕草が伝わる |
| `worried` | 8196152 | 191 | 71 | 601 | 眉を寄せ、口を閉じたまま顎の下で両手を組んでいる |
