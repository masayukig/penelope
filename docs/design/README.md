# penelope Web UI デザインの手引き（最初の版）

2026-11-14、本人と Claude design のキャンバスで詰めた結果。画面の一覧と流れ（オーナーとの合意）への答えにあたる。
Web UI（`packages/web`）はこの手引きと `src/*.dc.html` を正とする。採用しなかった PC の案 ①・② は写していない。

- 本人の確認: キャンバス上で見て「だいたい OK」。細部はまだ動くことがある。
- **依頼書との違い**: 依頼書は「アバターは出さない」「expression は今は表示しない」としているが、本人の判断で **アバターと expression を最初の版から出す** ことにした。この点は本書を優先する。

## 1. 考え方

Meta の Muse の構成（見た目ではない）を参考にした。会話が家で、1 本の長いやりとりが中心にある。その周りを 2 つに分ける。

| | 左（PC はレール、スマートフォンはメニュー） | 右（PC はパネル、スマートフォンは下からのシート） |
|---|---|---|
| 意味 | **場所を変える**。押すと真ん中が入れ替わる | **いまのエージェント**。会話の横に出るだけで、会話は消えない |
| 時制 | 過去と蓄え | 現在 |
| 中身 | 会話、活動の記録、記憶、出来事、設定 | アバターと expression、承認待ち、今の様子（今のターンの途中経過） |

- 承認待ちは「エージェントがいま止まって待っている」ことなので右に置く。答え終わった承認の履歴は、左の「活動の記録」に入る。
- 新しい承認待ちの印は、どの画面でもアバターの右肩に出る（キャンバスでは点線の丸で場所だけ示した）。
- サブエージェントが増えたら、右のパネルにエージェントごとの欄が縦に並ぶ（今は「（本体）」の見出しだけ置いてある）。
- 見た目の方向は「ゆったり見せる。ただし必要な情報には 1 操作で届く」。

## 2. ファイルの一覧

`src/` はキャンバスのアートボードそのもの（読み方は 7 章）。

| ファイル | 中身 | 実装するか |
|---|---|---|
| `Hybrid.dc.html` | **PC の画面（採用した案 ③）**。左のレール、会話、右のパネル | する |
| `Phone.dc.html` | **スマートフォンの画面**。浮いたアバターとメニュー、会話 | する |
| `PhoneSheet.dc.html` | スマートフォンで「いまのエージェント」のシートを開いた状態 | する |
| `Talk.dc.html` | 部品: 会話の時系列と入力欄。`mode`（busy / empty / offline）、`strip`、`attach` で状態が変わる | する |
| `Activity.dc.html` | 部品: 今の様子（状態と途中経過の流れ）。`idle` で「待っている」 | する |
| `Avatar.dc.html` | 部品: アバター（固定のアイコンと expression の札） | する |
| `Login.dc.html` | ログイン | する |
| `HybridDark` `HybridEmpty` `HybridOffline` `HybridAttach` | PC の状態（ダーク、空、接続切れ、添付）。`Hybrid` を引数つきで呼んでいるだけ | 状態の見本 |
| `PhoneDark` `PhoneEmpty` `PhoneKeyboard` `PhoneAttach` `LoginPhone` | スマートフォンの状態。`Phone` などを引数つきで呼んでいるだけ | 状態の見本 |
| `canvas.json` | キャンバス上の並びと題名 | 参考 |

## 3. PC（`Hybrid.dc.html`）

横に 3 つ並ぶ。

1. **左のレール**（幅 84px）: 会話、活動の記録、記憶、出来事、設定。アイコンと小さな文字（11px）。今いる場所は薄い地で示す。最初の版で中身があるのは「会話」だけで、ほかは後の波。
2. **会話**（残りの幅。中身は最大 720px で中央寄せ）: 上に高さ 56px の帯があり、右端に「状態の点と文字・名前・アバター（36px）」のボタンがある。押すと右のパネルが開閉する。その下が時系列と入力欄。
3. **右のパネル**（幅 380〜440px、開け閉めできる。最初は開いている）: 上から順に、アバターの舞台（120px のアバターと expression の札）、承認待ち、今の様子。タブはない。

## 4. スマートフォン（`Phone.dc.html`、`PhoneSheet.dc.html`）

- ヘッダーの帯はない。会話は画面の上端まで伸び、その上に **アバター（72px）が上の中央に浮く**。アバターの下に expression の札。名前は出さない。会話はアバターの下を流れる。
- 左上にメニューのボタンが浮く（丸い地）。開くと「場所」（会話、活動の記録、記憶、出来事、設定）。
- 入力欄のすぐ上に **状態の帯**（点、状態、いま使っているツール）。親指が届く位置。
- アバターか状態の帯を押すと、下から **シート**が出る。中身は PC の右のパネルと同じ（アバター 88px、承認待ち、今の様子）。
- 文字は 16px を基本にする（neutral の theme が、タッチで狭い画面のときにそうする）。
- 入力中（`PhoneKeyboard`）は、入力欄がキーボードの上に乗る。キャンバスではキーボードを描かず、領域だけ空けてある。
- ホーム画面に置いて開く（PWA）前提。

## 5. 会話と今の様子の中身

### 会話（`Talk.dc.html`）

- 新しいものが下。日付の区切り（「今日」）。
- **エージェントの返事**: 枠のない文章を左に。上に、アバター（28px）、名前、その返事の expression（文字）、きっかけの札（例「予約・毎朝 9:00」。Slack のメンションやアラートのときも同じ場所）。下に時刻。
- **オーナーのメッセージ**: 薄い地の吹き出しを右に。添付の画像は吹き出しの上に縮小して出し、押すと大きく見える。
- **考えている最中にオーナーがもう 1 通送ったとき**: すぐ時系列に並び、時刻の横に「考えている最中に届きました」と添える。今の様子の流れには「割り込み」として出る。
- **エージェントが考えているあいだ**: 時系列の最後に 3 つの点。
- **入力欄**: 角の丸い白い枠。複数行の文字、左下に添付のボタン、右下に送るボタン。
- **添付を付けたとき**（`attach`）: 入力欄の枠の中、文字の行の上に並べる。画像は 64px の縮小表示、画像以外はファイル名と大きさの札。それぞれ右肩の × で外す。スマートフォンでは横にスクロールする。
- **空のとき**（`mode=empty`）: 中央に文字だけ（「まだ会話はありません」「下の欄から話しかけてください。」）。
- **接続が切れたとき**（`mode=offline`）: 入力欄の上に知らせ（「接続が切れました。つなぎ直しています。書いたものは、つながってから送られます。」）。PC のヘッダーの状態は「接続なし」になる。この文言は、送信を溜めておく動きを前提にしている。そうしないなら文言を変える。

### 今の様子（`Activity.dc.html`）

- 一番上に状態: 「考えている」「ツールを使っている」「待っている」。点と文字の両方で示す（色だけにしない）。
- その下に、今のターンの途中経過を、ブロックが閉じるごとに上から順に流す。
  - ターンの始まり（時刻と、きっかけ）
  - 思考: 普段は 2 行に畳み、「全文を開く」で全部
  - ツールの呼び出し: 名前と引数を等幅で（例 `bash: kubectl get prometheus -n monitoring -o yaml`）
  - ツールの結果: 普段は畳み、「結果を開く」で等幅の枠（高さに上限、中でスクロール）
  - 割り込み: 色のついた地で目立たせる
  - 書いている途中のブロックは 3 つの点
- 待っているとき（`idle`）は流れを出さず、「いまは何もしていません。次の出来事を待っています。」

## 6. アバター

- 部品は 1 つ（`AgentAvatar`）。受け取るのは **expression と大きさ** だけ。画像と名前は設定から入る（コードに「ペネロペ」を書かない）。
- 最初の版: 固定のアイコン 1 枚と、expression を文字の札で添える。expression ごとに絵を差し替えることはしない。
- ゆくゆく 3D モデルなどに替えるときは、この部品の中身だけを差し替える。画面の側は触らない。
- 出る場所と大きさ: PC の右のパネルの舞台 120px（札つき）、PC のヘッダー 36px、スマートフォンで浮く 72px（札つき）、シートの舞台 88px（札つき）、返事の名前の横 28px（expression は名前の横に文字で）、ログイン 88px。
- キャンバスの丸い絵と、expression の語（「考え中」「ほっとした」）は仮のもの。expression の語の一覧はまだ決めていない。

## 7. `.dc.html` の読み方

- Claude design の「Design Component」という形の HTML。単体ではブラウザで開けない（`support.js` はキャンバスの側にある）。**値を読むための資料**として使う。
- 見た目はほぼすべて、要素のインラインの `style` に書いてある。余白、大きさ、角丸はそこから読む。
- 色は Astryx の変数名そのまま（`var(--color-background-surface)` など）。値は各ファイルの一番外の要素で `light-dark(明, 暗)` として定義してあり、`@astryxdesign/theme-neutral` 0.7.16 から写した。
- `{{名前}}` は末尾の `renderVals()` が返す値。`<sc-if value="{{x}}">` は条件つきの表示。`<dc-import name="Talk" …>` は `Talk.dc.html` をその場に置く、という意味で、ほかの属性は引数になる。
- 文言とデータ（Pod の名前、時刻、ファイル名など）はすべて例。

## 8. Astryx の部品との対応

キャンバスでは Astryx の本物の部品を動かせないので、**neutral の値を使って手で描いてある**。実装では下の部品で組み、見た目は Astryx の側に合わせる（キャンバスと数 px 違ってよい）。部品の名前は `@astryxdesign/core` 0.7.16 にあることを確かめたが、**props は確かめていない**。`npx @astryxdesign/cli component <名前>` で引くこと。

| 画面のもの | Astryx の部品 |
|---|---|
| 全体の枠、左のレール | `AppShell`、`SideNav`（`SideNavItem`）。スマートフォンのメニューは `MobileNav` |
| 会話の枠（時系列と、下に留まる入力欄） | `ChatLayout`（`density` は spacious を試す） |
| 時系列 | `ChatMessageList`、`ChatMessage`、`ChatMessageBubble`（エージェントは ghost、オーナーは filled）、`ChatMessageMetadata` |
| 日付の区切り | `ChatSystemMessage`（divider） |
| きっかけの札、expression の札 | `Badge` |
| 入力欄 | `ChatComposer`、`ChatSendButton`。添付の並びは `ChatComposerDrawer`、添付のボタンは `IconButton` と `FileInput` |
| 状態の帯（スマートフォン） | `ChatComposer` の `status` の枠 |
| 添付の縮小表示、大きく見る | `Thumbnail`、`Lightbox` |
| 空のとき | `EmptyState`（`ChatLayout` の `emptyState`） |
| 接続が切れた知らせ | `Banner` |
| 状態の点 | `StatusDot`（必ず文字を添える） |
| 途中経過の思考、ツールの結果の開け閉め | `Collapsible`。ツールの呼び出しは `ChatToolCalls` が合うか確かめる |
| ツールの引数と結果 | `Code`、`CodeBlock` |
| アバター | `Avatar`（中身は `AgentAvatar` で包む） |
| スマートフォンのシート | `BottomSheet`（つまみ、途中で止まる高さ） |
| PC の右のパネル | 専用の部品は見ていない。`Layout` のパネルの枠か `Resizable` を確かめる |
| ログイン | `Center`、`Button` |

## 9. theme

- theme は **neutral**（`@astryxdesign/theme-neutral`）。ライトとダークの両方。色・角丸・影の上書きは **していない**。
- 提案する上書きは 1 つだけ: 本文と見出しの書体の予備に、日本語の書体（`"Hiragino Sans", "Noto Sans JP"`）を足す。neutral の書体 Figtree には日本語の字形がないため。
- キャンバスで使った主な値（確かめ用）:

| 変数 | ライト | ダーク |
|---|---|---|
| `--color-background-body` | `#f1f1f1` | `#1b1b1b` |
| `--color-background-surface` | `#ffffff` | `#262626` |
| `--color-text-primary` | `#000000` | `#ffffff` |
| `--color-text-secondary` | `#474747` | `#9e9e9e` |
| `--color-border` | `#00000014` | `#ffffff1A` |
| `--color-neutral`（吹き出し、札の地） | `#0000000F` | `#ffffff1A` |
| `--color-accent` / `--color-on-accent` | `#1b1b1b` / `#ffffff` | `#f1f1f1` / `#111111` |
| `--color-text-info`（「考えている」の点） | `#0067ce` | `#a1caff` |
| `--color-info-muted` / `--color-on-info-muted`（割り込み） | `#b9d7ff` / `#003978` | `#88bcff3D` / `#a1caff` |
| `--color-warning-muted` / `--color-on-warning-muted`（接続切れ） | `#fae19e` / `#4b3900` | `#e2b6233D` / `#eec448` |
| 角丸 | `--radius-element` 0.625rem、`--radius-container` 0.75rem、入力欄は `--radius-chat` 28px | |

## 10. まだ決めていないこと

- expression の語の一覧と、アバターの実際の絵。
- 承認待ちの中身（今回は置き場所だけ。空のとき「いまはありません」と出すか、欄ごと消すか）。
- 活動の記録、記憶、出来事、設定の画面（左の「場所」に入ることだけ決めた）。
- PC でパネルを閉じているとき、アバターはヘッダーの 36px だけになる。3D モデルを常に見せたくなったら、パネルを開いたまま固定する操作を足す。
- 画像（PNG）の書き出しは、本人がキャンバスから行う。
