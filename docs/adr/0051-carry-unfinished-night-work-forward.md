# 0051. 照合と整理の基準は別々に持ち、成功したときだけ進める

- Date: 2026-11-21
- Status: Accepted

## Context

夜の切り替えでは、照合係が日中のメモを原本で確かめ、整理係が長期記憶の構成を整える。runner は両方に同じ基準 `nightMemory` との差分を渡す。新しい日中のセッションを開始するときにこの基準を取り直すため、照合や整理が失敗しても、開始に成功すれば基準は進む。次の夜の差分には、失敗した係が見られなかった変更が出なくなる。また、照合に渡す記録はその日のセッションから決まるので、照合できなかった日の記録は持ち越されない。

## Decision

- 変更一覧の基準は照合係と整理係とで独立させ、各段が成功したときだけ、その段の基準を進める。棚卸しでは整理係の 2 ターンを同じ段として扱う。失敗した段の基準は進めず、次の夜に前回成功時からの変更一覧を再び渡す。次のセッションを始めるかどうかとは切り離す。
- 照合係には、今回の記録に加え、未照合の日の日中のセッションの記録のパスを渡す。照合に必要な原本だけを読み取りで渡す範囲は変えない。持ち越す日数には上限を設け、それを超えた古い分は照合対象から落とし、活動の記録に出す。原本自体の保存期間は変えない。
- 途中の段が失敗しても後続の段に進み、新しいセッションの開始を試みる。持ち越しは次の夜の入力で行い、日中のセッションをやり直さない。

### 本 ADR で決定しないこと

- 未照合の記録を持ち越す日数、基準と未照合の記録の持ち方（委譲先: 設定と実装）
- 活動の記録の欄と表示（委譲先: UI 向けの API の仕様書「活動の記録」）
- オーナーの操作で夜をやり直す入口（委譲先: 必要になった時点の別 ADR）

## Consequences

- 翌日の仕事を止めずに、照合や整理で残した仕事を次の夜に見直せる。片方の失敗で他方が同じ差分を調べ直す必要はない。
- 失敗が続けば入力が増える。未照合の期間を際限なく伸ばさず、対象から外れたことをオーナーが分かるようにする。持ち越しは段の入力を取り直す仕組みであり、失敗したターンによる変更を取り消すものではない。
